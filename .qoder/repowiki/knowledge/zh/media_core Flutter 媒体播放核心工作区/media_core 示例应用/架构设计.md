示例应用以 `lib/main.dart` 为入口，初始化 `MediaKitPlayerAdapter`、开启 `MediaCoreLog.debug` 日志并尝试启用 `MediaSessionBootstrap.enable()` 系统媒体面，随后启动 `MaterialApp`。

- 顶层目录按 Flutter 标准划分：`android/`、`ios/`、`linux/`、`macos/`、`windows/`、`web/` 提供各平台原生壳；`pubspec.yaml` 声明对 `media_core` 及 `media_core_media_kit`、`media_core_logging`、`media_core_memory`、`media_core_live`、`media_core_feed`、`media_core_audio`、`media_core_presentation`、`media_core_danmaku`、`media_core_multiview`、`media_core_list_playback`、`media_core_download`、`media_core_recording_ffmpeg`、`media_core_ui`、`media_core_native`、`media_core_mediasession` 等依赖。
- `lib/` 内分三层：
  - `pages/`：每个可运行的真实播放页面（player、live、feed、music、presentation、multiview、memory、media_session、ui_styles），对应一个 `RunnableDemo`。
  - `demos/console/`：纯 Dart 逻辑演示（cache、pool、queue、lyric、source、platform、probe、task、fault、download、recording、background_execution、logging、list_playback、memory），实现 `ModuleDemo` 接口并通过 `run()` 输出控制台结果。
  - `demos/fakes/`：`FakePoolPlayer`、`FakeDownload`、`FakeFFmpeg` 等桩对象，使 multiview 墙与 memory 仪表盘在无后端/无网络环境下仍可运行。
  - `demos/module_demo.dart` 与 `demos/runnable_demo.dart` 定义两类 demo 契约（`ModuleDemo` + `ModuleCategory` 枚举、`RunnableDemo` 数据类）。
  - `demos/registry.dart` 集中注册所有 demo，是 UI 层唯一的数据源。
  - `ui/` 提供共享脚手架：`module_catalog_page.dart`（首页目录）、`module_demo_page.dart`（纯逻辑 demo 详情）、`demo_page_scaffold.dart`、`demo_log.dart`。
  - `language.dart` 提供 `DemoLanguageNotifier` / `DemoLanguageScope` 双语文档切换。
- 依赖方向单向：`main → registry → pages/demos/console/fakes`，UI 层不反向依赖具体 demo 实现，新增 demo 只需在 `registry.dart` 中追加条目。
