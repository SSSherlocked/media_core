根 `pubspec.yaml` 通过 `workspace:` 声明 24 个 `packages/media_core_*` 子包 + `example`，由 melos 驱动跨包构建；`media_core` 内核（纯 Dart）定义 `PlayerKernel` / `PlayerHandle` / `RecoveryLadder` 等契约，各能力包（ui、mediasession、native、live、feed、audio、download 等）通过 `KernelAudioDriver` / `KernelPresentationDriver` / `PlatformProvider` 等接口反向挂接，核心不反向依赖任何能力包，实现“能力靠声明”的松耦合。
- 后端适配层：`media_kit`（vendor）、`ijk_player`、`better_player`、`fvp` 四套引擎经 `PlayerAdapterRegistry` 按协议/格式/直播能力打分选择。
- 基础设施层：`media_core_logging`（分级日志枢纽）与 `media_core_memory`（内存记账）被所有能力包共享。
- 示例应用 `example_app` 作为端到端演示，覆盖全部能力模块。
- 文档集 `docs` 提供 zh-Hans/en/zh-Hant 三语架构与 API 说明，与代码同步发布。
- 根级 `melos` 脚本统一执行 `gen`（build_runner）、`analyze`、`format`、`kareki`（死码扫描），保证全仓库 lint/format/codegen 一致。
