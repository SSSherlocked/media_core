- 能力包通过 KernelAudioDriver / KernelPresentationDriver / PlatformProvider 等接口向内核注册，核心包不反向依赖能力包
- 能力与设备事实以可空值表达“未知”，而非把沉默视为不支持
- 公开操作进入队列串行执行，任务队列与代际守卫是正确性唯一门，不使用散落布尔标志
- 错误恢复收敛到 RecoveryLadder 单一决策点，通过 reportFailure 上报、recoveryEvents 观察
- 模块 library.dart 由 build_runner 生成并带 GENERATED MODULE LIBRARY 头，新增模块需手工补导出
